Take the project
home.

Clone the repository, add your Groq key locally, and run the course pages or the LLM integration demo.

1. Clone

git clone https://github.com/gksoriginals/lbs-full-stack-ai.git
cd lbs-full-stack-ai

2. Create a Groq API key

Open Groq Console → API Keys, create a key, then choose an available chat model from the Groq model list.

3. Add your Groq key and model

GROQ_API_KEY=gsk_your_key_here
GROQ_MODEL=openai/gpt-oss-20b

Save these two lines in a file named .env at the project root. It is ignored by Git.

4. Run the course pages

python3 -m http.server 8765 --directory docs

Open http://127.0.0.1:8765 in a browser.

5. Run the LLM demo

python3 -m pip install openai python-dotenv
cd docs/demo
python3 policy_assistant_demo.py

Open http://127.0.0.1:8080.

Keep your key private. Do not commit or share the root .env file.
