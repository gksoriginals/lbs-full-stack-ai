LBS College
assistant

This GitHub Pages site hosts the course material and source files. The Python server retrieves curated official LBS College chunks and sends only those chunks to Groq; the API key stays private.

Run locally

cd docs/demo
python3 -m pip install openai
export GROQ_API_KEY="..."
export GROQ_MODEL="openai/gpt-oss-20b"
python3 policy_assistant_demo.py

Then open http://127.0.0.1:8080. The knowledge base is lbs_knowledge_base.json; change it to add new curated official chunks.
